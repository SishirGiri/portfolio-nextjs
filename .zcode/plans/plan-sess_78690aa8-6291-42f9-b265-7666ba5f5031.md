### Implementation approach per spec area
- **Map**: seeded tile grid (asphalt roads with dashed lane markings, sidewalks, crosswalks, districts: residential/commercial/industrial/park). Buildings drawn as 2.5D with shadows. `mapObjects.js` replaces every colored square with a realistically-shaped object (cars with windshields, containers with ribs, trees with canopy+trunk, etc.).
- **Player**: 8-direction movement vector, body angle follows movement, weapon angle follows mouse. Sprint (stamina), roll (dash + i-frames + cooldown), reload with anim, armor absorbs % damage before health.
- **Weapons (7)**: Pistol, SMG, Assault Rifle, Shotgun (pellets+spread), Sniper (high dmg/zoom scope), Frag grenade, Flashbang (whiteout + stun), Smoke (LOS blocker). Each has damage/fire-rate/recoil/recovery/spread/mag/reload/bullet-speed. Recoil kicks aim and recovers.
- **Enemy AI**: state machine. Patrol waypoints → hear gunfire (sound radius) → investigate last known pos → LOS via grid raycast → chase → score nearby cover → flank via pathfinding → shoot with tier-based accuracy/spread → search on LOS loss → return to guard. Tiers: thug → soldier → elite.
- **Vehicles**: enter/exit, accel/brake/steer with momentum, tile+object collision, damage on impact, headlights at night, explode at 0 hp. Types: sedan, police (lights+siren), SUV, truck.
- **NPCs**: civilians flee gunfire, police engage enemies, hostages cower/follow when rescued, shopkeepers idle.
- **Missions (7)**: eliminate targets, rescue hostages, secure building, defuse bomb (timer), escort VIP, capture criminal, collect intel. Each gives objective markers, optional timer, money+XP reward, completion screen.
- **HUD**: health/armor bars, current weapon icon + ammo (mag/reserve), grenade counts, money, XP bar + level, compass (N/E/S/W + objective bearing), kill counter, mission timer, objective list, hit markers, damage direction indicators.
- **Graphics**: dynamic lighting (radial gradients around player/streetlights/headlights at night), shadows, bullet tracers, particle systems (blood, sparks, smoke, explosions, shell casings), weather (rain streaks, fog overlay), day/night cycle (sky color + light intensity + neon).
- **Physics**: tile + AABB collision, LOS via DDA grid raycast, bullet penetration through thin objects (optional, tier-based), destructible objects (barriers break, barrels explode chain), explosive barrels.
- **Audio**: per-weapon synthesized gunshots, footsteps (pitch-vary), reload clicks, vehicle engine (RPM-based), tire/crash, explosions, ambient city bed, background music loop. Toggle saved to localStorage.
- **Code structure**: OOP classes, ES6 modules, 60 FPS via `requestAnimationFrame` with delta-time, camera follows player with look-ahead, world (e.g. 200×200 tiles) larger than screen, asset preload phase, responsive canvas (resize/DPR), save/load to localStorage (progress, weapons, money, level, settings).
- **Mobile**: virtual joystick + aim-assist + action buttons (fire/reload/roll/grenade/enter), scroll-locking. (Matches existing pattern.)
