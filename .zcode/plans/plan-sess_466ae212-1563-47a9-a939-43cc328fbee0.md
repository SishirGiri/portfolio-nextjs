# Premium About Page Redesign

Redesign `/about` into a premium, modern developer-portfolio page. **No Skills section, no tech list** — content stays focused on personality, journey, goals, and what I enjoy building. Reuse the existing dark cyber-noir theme (cyan glow, glassmorphism, design tokens) and layer Framer Motion + lucide-react on top.

## File changes

### 1. New section components — `src/components/About/`
Split into focused, reusable client components (all `'use client'`). Each uses **Framer Motion** (`whileInView` + `viewport={{ once: true }}` + `staggerChildren`) for fade/slide/scale/stagger/scroll-reveal, plus `whileHover={{ y: -6 }}` for hover-lift. Icons from `lucide-react@1.16` (verified available).

## Design / animation contract
- Theme: dark `--bg`/`--bg-2`, cyan glow, glassmorphism `backdrop-filter: blur(16px)`, gradient text `linear-gradient(135deg, #fff, var(--cyan), var(--violet))` — identical to existing hero/project pages.
- Animations: Framer Motion fade/slide/scale/stagger/scroll-reveal + hover-lift + floating keyframes (`floatOrb` reuse + new `floatY`). All animation wrapped in `prefers-reduced-motion` respected (existing global rule neutralizes it).
- Responsive down to 360px; touch devices get hover effects disabled (existing global rule).
- **No Skills section, no tech list, no overlap with Skills page content.**
