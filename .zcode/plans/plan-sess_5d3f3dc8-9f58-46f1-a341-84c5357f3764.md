### Animation plan (Framer Motion, reduced-motion safe)
- Hero: staggered word reveal + scroll indicator + floating orbs + mouse spotlight.
- Filter: `layoutId` shared element for active-pill glow; grid uses `AnimatePresence` + `layout` for smooth filter transitions.
- Cards: stagger-in, hover lift, image zoom, gradient overlay, tilt (TiltCard), mouse-follow glow, tech-badge stagger on hover, button fade-in.
- Modal: backdrop fade + panel scale/translate; ESC + scroll-lock; `prefers-reduced-motion` disables transitions.
- Stats: count-up on in-view.
- Timeline: slide-in steps + animated connector.
- Touch: disable tilt/lift/spotlight.

### Responsive
- Grid: 3-col desktop → 2 tablet → 1 mobile. Filter bar horizontally scrollable on mobile. Featured/stats/timeline collapse to stacked layouts.
