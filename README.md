# portfolio-nextjs

Personal portfolio of Sishir Bharati — Aspiring Developer and AI Enthusiast from Nepal.

Built with **Next.js 16**, **Three.js**, **TypeScript**, and **Tailwind CSS**.

## Features

- Dark cyber-noir futuristic theme
- Three.js particle nebula + DNA helix hero animation
- Scroll reveal animations
- Responsive design
- Contact form with Formspree integration
- Custom cursor effects

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

### Vercel Deployment

1. Push this repository to GitHub
2. Import the project in [Vercel](https://vercel.com)
3. Vercel will automatically detect Next.js and configure the deployment
4. Or deploy using Vercel CLI:

```bash
npm install -g vercel
vercel
```

### Build for Static Export

```bash
npm run build
```

This creates a static export in the `out/` directory ready for deployment.
